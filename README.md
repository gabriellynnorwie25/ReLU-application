# ReLU Activation Function

## 1. Project Overview

This project is a web application developed to visualise the Rectified Linear Unit (ReLU) activation function used in neural networks. The application is developed using Python and Streamlit.

Users can change the input value using an interactive slider. The application automatically calculates the output and displays the ReLU graph.

## 2. Activation Function

ReLU is an activation function that returns 0 when the input value is negative and returns the same value when the input is positive.

**Formula:**

f(x) = max(0, x)

## 3. Technologies Used

- Python
- Streamlit
- NumPy
- Matplotlib
- Visual Studio Code

## 4. Application Features

- Interactive slider to select an input value.
- Automatic calculation of the ReLU output.
- Graphical visualisation of the ReLU function.
- Explanation of how the function works.

## 5. Installation

Install the required libraries using:

```bash
pip install streamlit numpy matplotlib
```

## 6. How to Run

Run the following command in the VS Code terminal:

```bash
streamlit run relu_app.py
```

The application will open in your web browser.
